# 暮らしの道具箱

Claudeと一緒に作る、自分専用の小さな道具集です。仕事用ではなく、日々の暮らしや趣味の中で使うための道具を、思いついたときに1個ずつ作って並べています。

道具はすべて「1枚の自己完結HTMLファイル」として作られています。インストールもアカウント登録も不要で、ブラウザで開くだけで動きます。道具本体は [tools/](tools/) フォルダに置いています（後述の理由により、一覧ページからはリンクしていません）。

このプロジェクトの詳しい考え方・経緯は [handoff.md](handoff.md) にまとめています。

## 道具一覧

- **通学バス**（`tools/` の中にあります）：桂駅西口⇄桂御陵坂の区間で、回数券が使える京阪京都交通の便だけを絞り込んで表示します。京都市バス（西6号系統）も同じ区間を走りますが、回数券が使えないため意図的に除外しています。

## ダイヤ改正があったときは

通学バスの時刻表はHTMLファイルの中に直接書き込んでいるので、京阪京都交通のダイヤ改正があったら書き換えが必要です。Claudeに「通学バスの時刻表を最新に更新して」と頼めば、以下の作業をしてくれます。

書き換える場所は、道具のHTMLファイル内の2か所です。

1. **`TIMETABLE`**（発車時刻）… 公式サイトの時刻表ページから取得します。
   - 桂駅西口 `https://www.keihankyotokotsu.jp/bustimetable/timetable.php?stop_cd=1036&no=1`
   - 桂御陵坂 `https://www.keihankyotokotsu.jp/bustimetable/timetable.php?stop_cd=1065&no=1`
   - どちらも静的なHTMLの表なので、`curl` で取得してそのまま読み取れます。表中の「＊」（市バス定期券が使える印）や「★」（おりばステーション停車の印）は発車時刻とは無関係なので落とします。
2. **`RIDE_TIME`**（乗車時間）… 公式の通過時刻表PDF `https://www.keihankyotokotsu.jp/pdf/timetable.pdf` から求めます。
   - `mutool draw -F txt -o - timetable.pdf` でテキスト化できます。
   - 「桂坂線」のページで、桂駅西口と桂御陵坂それぞれの通過時刻を突き合わせて差を取ります。
   - **系統20と20Bで所要時間は変わりません。**変わるのは時間帯です（同じ20Bでも13:32発は12分、17:01発は13分）。この点は間違えやすいので注意してください。

書き換えたあとは、公式サイトの便数と道具側の便数が一致するか照合すると安心です。

## 公開について

このリポジトリはGitHub Pagesで公開していますが、**道具のファイル名は推測できないランダムな文字列**にしてあり、[index.html](index.html) やこのREADMEからはリンクしていません。URLを知っている本人以外がたどり着けないようにするためです。あわせて [robots.txt](robots.txt) と各ファイルの `noindex` 指定で、検索エンジンにも載らないようにしています。

新しい道具を追加するときも、同じようにランダムなファイル名を使い、一覧ページからはリンクしないでください。
